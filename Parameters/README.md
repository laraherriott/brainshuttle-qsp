# Parameters README

This folder contains healthy base model parameters and PK and PD parameters for the one antibody model for overwriting model defaults (which correspond to lecanemab in a disease base model).

---

## File/Folder Listings

| File/Folder Name         | Description / Source / Notes                         |
|-------------------------|-------------------------------------------------------------------|
| `healthy.csv`        | Amyloid synthesis, aggregation, transport and clearance parameters for simulating the healthy base model    |
| `one_ab.csv`        | PK and PD parameters for simulating treatment with anti-amyloid monoclonal antibody       |
